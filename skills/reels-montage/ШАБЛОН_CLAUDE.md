# Проект: рилс для Instagram

## Цель
(О чём рилс, для кого, что должен почувствовать зритель. Одна-две строки.)

## Требования
- Формат: вертикальный 1080×1920, монтаж через скилл `reels-montage`.
- Способ: «Конторка» (ИИ-кадры-шаржи + мои кадры, без DaVinci) / классический (быстрые кадры + чёрные вставки, DaVinci Resolve Studio)
- Длина: (например, 30–50 секунд, или «сколько получится по голосу»)
- Стиль: (любимые аккаунты-референсы; что нравится: быстрые кадры / субтитры по одному слову / чёрные вставки)
- Музыка: без музыки (наложу в Instagram) / вот мой трек: (файл)
- Нельзя показывать: (люди, места, кадры, которые не нравятся)

## Где что лежит
- `видео/` — исходники с телефона.
- `голос.m4a` — запись голоса (несколько дублей подряд — нормально). Нет записи — можно озвучить текст через `tts.sh`.
- `картинки/` — ИИ-кадры для «Конторки» (если этот формат).
- `монтаж/` — готовые версии рилса; `монтаж/_данные/` — служебные файлы (план кадров, нарезка голоса).
