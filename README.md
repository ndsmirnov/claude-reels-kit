# claude-reels-kit — автомонтаж рилсов в Claude Code

Два скилла для [Claude Code](https://claude.com/claude-code), которые превращают Claude в монтажёра и сценариста вертикальных видео (Instagram Reels, TikTok, Shorts):

- **reels-montage** — монтирует рилс из твоей голосовой записи и видео с телефона: вырезает паузы и неудачные дубли, выравнивает громкость голоса, делает субтитры по одному слову, графику и ИИ-кадры поверх видео, выравнивает цвет и проверяет звук.
- **reel-remix** — находит залетевшие рилсы в твоей нише по хештегам, разбирает лучший на раскадровку и пишет под твою тему сценарий с 2–4 вариантами хука.

**Что получится на выходе:** готовый `mp4` 1080×1920 (около −14 LUFS, как у популярных аккаунтов), несколько версий рядом для сравнения, плюс текстовый сценарий и раскадровка референса.

Автор: Никита, канал [t.me/put_chelovecheskiy](https://t.me/put_chelovecheskiy).

## Что нужно

| Что | Зачем | Как поставить |
|---|---|---|
| Mac (macOS) | скрипты написаны под macOS (шрифты, распознавание лиц Apple Vision) | — |
| Claude Code | в нём работают скиллы | [claude.com/claude-code](https://claude.com/claude-code) |
| Python 3 | расшифровка голоса (whisper), звук, субтитры | `xcode-select --install` |
| ffmpeg | вся работа с видео и звуком | `brew install ffmpeg` |
| Node.js 20+ | слой графики (Remotion) и парсер рилсов | `brew install node` |
| Xcode Command Line Tools | собрать маленькую программу поиска лиц, чтобы текст не закрывал лица | `xcode-select --install` |
| Аккаунт Apify и API-токен | только для reel-remix (поиск рилсов) | apify.com → Settings → Integrations → API token |
| DaVinci Resolve **Studio** | только для «классического» монтажа через `resolve_build.py`. В бесплатной версии DaVinci внешние скрипты не работают. Формат «Конторка» собирается без DaVinci | blackmagicdesign.com |
| Google Chrome (желательно) | Remotion рендерит графику через браузер; если Chrome нет, Remotion скачает свой | — |

Если нет Homebrew (`brew`): сначала поставь его по инструкции с [brew.sh](https://brew.sh).

## Установка

### Вариант А — попроси Claude

Открой Claude Code и напиши:

«Установи скиллы из https://github.com/ndsmirnov/claude-reels-kit: склонируй репозиторий и запусти setup.sh. Токен Apify вставлю сам.»

### Вариант Б — вручную

```
git clone https://github.com/ndsmirnov/claude-reels-kit.git
cd claude-reels-kit
mkdir -p ~/.claude/skills && cp -R skills/* ~/.claude/skills/
bash setup.sh
```

`setup.sh` проверит программы и подскажет, чего не хватает, затем: скопирует скиллы в `~/.claude/skills/`, парсер в `~/reels-parser/` (и создаст там `.env`), соберёт программу поиска лиц, положит шрифты, поставит Remotion и Python-пакеты в `~/reels-work` (первый раз — несколько минут).

После установки:
1. Впиши токен Apify в `~/reels-parser/.env` (строка `APIFY_TOKEN=...`) — нужно только для reel-remix.
2. Перезапусти Claude Code. Проверка: напиши `/` — в списке должны быть `reels-montage` и `reel-remix`.

Своя рабочая папка вместо `~/reels-work`: `REELS_WORKDIR=~/моя-папка bash setup.sh`.

## Как пользоваться

1. Создай папку под рилс, например `~/reels/первый`, и положи туда видео с телефона (папка `видео/`) и запись голоса (`голос.m4a`; несколько дублей подряд — нормально).
2. Скопируй в неё `~/.claude/skills/reels-montage/ШАБЛОН_CLAUDE.md` под именем `CLAUDE.md` и заполни 5 строк (цель, длина, стиль, что нельзя показывать). Можно не заполнять — Claude сам спросит.
3. Открой Терминал, `cd ~/reels/первый`, запусти `claude` и пиши обычными словами:

- «Смонтируй рилс: видео в папке видео, голос — голос.m4a. Быстрые кадры, субтитры по одному слову, без музыки.»
- «Сделай рилс в формате Конторка про то, как я автоматизировал отчёты.»
- «Найди залетевшие рилсы по нише фитнес и разбери лучший на раскадровку.»
- «Напиши сценарий и дай 3 хука под тему “как я ушёл с найма”.»

Claude сначала покажет план и спорные места, потом соберёт версию v1. Правки давай одной пачкой («на 8 секунде убери кадр, там не я», «цвет теплее») — каждая правка получает новую версию, старые остаются.

**Куда класть свои картинки и видео для графики.** Указывай их в задании абсолютными путями (или просто положи в папку рилса) — `remotion/render.sh` сам скопирует нужное в `remotion/public/`. Папка `remotion/public/` в репозитории пустая (`.gitkeep`): её содержимое — твои личные медиа, в git оно не попадает.

## Что бесплатно, а что платно

- **Бесплатно:** сами скиллы и скрипты, ffmpeg, whisper (расшифровка на твоём компьютере), Python, Node.
- **Remotion** — бесплатен для частных лиц и компаний до 3 человек; для компаний крупнее нужна их лицензия (remotion.dev/license).
- **Claude Code** — нужна подписка Claude или API-ключ Anthropic.
- **Apify** (reel-remix) — даёт бесплатные $5 в месяц; ориентир: 100 рилсов без расшифровки ≈ $0.26, расшифровка ≈ $0.07 за рилс. Скилл сначала делает дешёвый тест на 5 роликов.
- **DaVinci Resolve Studio** — платная (разовая покупка); нужна только для классического пути через DaVinci.
- **Необязательно:** пробная озвучка текста через fish.audio (`tts.sh`, бесплатная модель, нужен свой ключ `FISH_API_KEY`); ИИ-картинки для «Конторки» через Codex CLI (`gen_image.sh`, нужна подписка ChatGPT).

Ключи и токены храни только у себя (`.env`, переменные окружения) и никому не отправляй — к ним привязана оплата.

## Честно о границах

- Claude не узнаёт тебя в кадре: чужих людей в клипах может не отличить. Посмотри готовое видео целиком перед публикацией.
- На слух и «красоту» Claude не проверяет — он меряет громкость, спектр и смотрит на сетку кадров. Финальное решение за тобой.
- Скрипты сборки при первом запуске могут потребовать доводки под твои файлы — попроси Claude проверить длину и число кадров.
