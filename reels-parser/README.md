# reels-parser

Сбор рилсов Instagram через Apify: поиск по хештегам, метрики аккаунта, транскрипты. Работает в паре со скиллом `reel-remix` для Claude Code.

## Настройка

```
cp .env.example .env
# вставить в .env свой токен: apify.com → Settings → Integrations → API token
```

## Скрипты

- `fetch-hashtags.js "тег1,тег2" [лимит]` — свежие рилсы по хештегам (для поиска референсов).
- `fetch-account.js <username> [лимит]` — метрики и подписи всех рилсов аккаунта (дёшево, без транскрипта).
- `fetch-transcripts.js <файл-со-списком-URL>.json` — транскрипты конкретных рилсов (дорого, брать точечно).
- `analyze.js` — локальная статистика по `output/*.json` (бесплатно).
- `score-reels.js <файл>.json` — ранжирование по критериям из `lib/score.js` (бесплатно).

Запуск: `node --env-file=.env <скрипт>`.

## Стоимость (ориентир)

- 100 рилсов без транскрипта: около $0.26.
- Транскрипт: около $0.067 за рилс.
- У Apify есть бесплатные $5 в месяц, на тесты хватает.
